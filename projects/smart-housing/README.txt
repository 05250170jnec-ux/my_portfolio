SMART HOUSING - RENTAL HOUSE FINDER

Concept: a system where people can search rental houses in one place instead of searching everywhere.

Technology: Python, Tkinter, SQLite.

Users: tenants/house seekers and landlords/property managers.

Features: search by location, rent range, bedrooms and house type; view details; CRUD listing management; availability status; dashboard; CSV export; validation.

Run: python smart_housing_system.py

The database smart_housing.db is created automatically with sample listings on first run.
