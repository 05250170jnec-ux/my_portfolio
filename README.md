# Dechen Pem - Personal Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Features
- Home, About, Skills, Projects, Education and Contact sections
- Dark/light theme toggle, mobile menu, scroll highlighting, animated skill bars
- Background video with sound (assets/background.mp4)
- Contact form that opens the visitor's email app

## Files to add in the assets folder
- profile.jpg (included), bumthang.jpg, edu-samdrup.jpg, edu-drukgyel.jpg, edu-debsi.jpg (optional edu-jnec.jpg), background.mp4 (included)

## Run locally
Open index.html in a browser.
